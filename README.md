# MonkeyPy
A simplified python transpiler for developing Garmin Connect software

## Overview
MonkeyPy is a python library that transforms python code into a workable and usable Monkey C file, suitable for creating apps for the Garmin Connect IQ platform.
The complicated and tedious aspects of Monkey C are handled by MonkeyPy, allowing developers to focus more on the main content of their apps rather than the complicated and often confusing programming aspects in Monkey C.

Drawing elements, system storage, sensor information and more are all simplified into python code, handling dependencies and memory management behind the scenes.
